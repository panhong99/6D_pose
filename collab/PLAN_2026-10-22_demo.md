# 10/22 내부 발표 시연 계획 (10/13 보스 미팅)

## 현재
- 접시 잡기 + 바구니 넣기(place) 실기 시연 확인 완료. 넣는 곳은 로봇 기준 3사분면.

## 10/22까지 (우선순위)
1. **바구니 위치 자유도**: 로봇 팔이 닿는 범위 안이면 정말 아무 데나(지금 접시를 두는 +y 쪽 포함; 현재는 −y 쪽만 됨) 두어도 인식하고 넣기. 자유도는 항상 '팔이 닿는 범위 안'을 뜻함.
2. **바구니 4사분면 넣기**: 바구니에 붙은 ArUco 마커 4개로 중심점 → 로봇 기준 4분면으로 나누고, 지정한 분면에 넣기.
3. **분면 안 핀 번호 매기기 + 지정 번호에 넣기** (2와 함께): 손목 카메라(또는 고정 카메라 확대)로 해당 분면을 보고, 좌-우로 나란히 정렬된 핀 두 개를 한 쌍(pair)으로 묶은 뒤, 손목 카메라 화면 기준 **위→아래** 순서로 1번부터 번호. CV 모델이 필요하면 요청.
- 목표 시연: 4개 분면에 접시를 하나씩.
- 같이 할 것: 하강 전 이동 속도 올리기(진행 중), 바구니 ArUco 마커 크기 10 → 5 → 2.5 cm로 줄이며 인식 정확도 비교.

## 10/22 이후
- failure detection(잘못된 번호에 넣으려 할 때 스스로 알아차리고 다시 맞추기) — 본격 DL/RL 학습 구간, 선행 연구 조사 후 설계.
  - task 1: 빈 바구니에서 지정 번호에 넣기 + 잘못된 번호 인지·재조정.
  - task 2: 다른 접시들이 이미 꽂힌 상태에서 장애물을 피해 지정 번호에 넣기(비전으로 빈 자리 검출 + RL, IK/FK 없이 관절값으로 푸는 것이 가능한지 검토).
- N개 접시 전체 검출 후 순서대로 pick and place.
- 판단: 손동작(그리퍼)은 학습할 필요가 적음(적당한 높이에서 접시를 수직으로 맞춘 뒤 내리면 들어감). 학습은 failure detection 쪽이 sim2real 간극을 메우는 연구로서 의미가 있음.

## 설계 (10/13 오후, Claude)
### 도달 범위 지도 (`python calibration/plate_plans.py basket_reach`, 결과 `calibration/data/basket/reach_20261013_174946/`)
- 조건: 바구니 회전 0°, 분면마다 가운데 틈(5번째), 접시 수직(정책과 같음), 접시 중심 바닥 위 18 cm, 시작 자세는 11 cm 위. IK + 실제 관절 한계(J5 ±135°) + 프레임·테이블 여유, 접시를 쥔 테두리 위치(φ)는 ±90° 안에서 탐색. 손 안 접시는 17:21 실기 잡기에서 계산.
- 결과(바구니 중심 기준): 가까운 분면 Q3·Q4는 x ≤ 1.15 m, 먼 분면 Q1·Q2는 x ≤ 0.85~0.90 m, **4분면 모두: x 0.50~0.85 m, y −0.35~+0.35 m 전체(±y 양쪽)**. 오늘 실기 자리(1.09, −0.20)는 Q3·Q4만 가능 = 실기와 일치.
- 고정 카메라: 바구니 중심 y ≤ +0.20이면 마커 4개, +0.25 이상이면 3개(피팅은 3개로 가능).
- 아직 안 본 것: 팔·그리퍼 vs 바구니 벽, 이미 꽂힌 접시, 테이블 가장자리·프레임 기둥(x 0.85, y ±0.56)과 바구니 몸체 겹침, 바구니 회전 ±15°, 손목 카메라 '보기 자세' 도달.
### 구조 (학습 없이 기하 + 손목 카메라 보정, 미팅 결론과 같음)
1. 고정 카메라 마커 → 바구니 자세(오차 수 mm).
2. 지정 분면 위 '보기 자세'로 이동 → 손목 사진에서 모델 핀 쌍을 투영하고 실제 핀(가는 세로선)을 찾아 맞춤 → 위→아래로 쌍 번호 → 지정 번호 틈 위치를 mm 단위로 보정.
3. 넣기: 틈 위 시작 자세(IK, φ 탐색) → 수직 하강(촘촘, 느리게) → +5 mm → 놓기 → 수직 상승 → 홈. 운반은 티칭 경로 대신 IK + 충돌 여유 계획.
4. 실행 옵션: `--quadrant Q1..Q4 --pin N`.
- 현재 BC+RL 정책은 −y 쪽 Q3에서만 학습됨 → 4분면·양쪽 자유도에는 기하 넣기를 기본으로, 정책은 비교용.
